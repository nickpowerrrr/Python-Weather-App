# Python-Weather-App
Simple weather app using an API and TKinter to make the UI

# Technologies
* ```Python``` As programming language
* ```Tkinter``` For the UI

# Features
* A UI displaying the current weather for three locations
* Locations can be changed with code (see app.py)

# Running (EXE)
1. Clone repository
2. Open ```dist```
3. Execute ```app.exe```

# Running (manual install)
1. Download Python 3.13
2. Download modules: ```Tkinter, PIL```
3. run app.py
